# Harvest Power – COS10026 Applied Web Project (Part 1)

Group 03 website for a fictional sustainable energy company (industry G03 – Sustainable Energy Solutions Company).
Static website built with HTML5 and CSS3 only (no JavaScript, no frameworks).

- Live site: https://sonyarmstrong1127.github.io/cos10026-group03/

    jobs.html         Job descriptions

    about.html        About the team
    styles/styles.css One shared stylesheet, one section per page owner
    images/           Logo and page images

## How to view
Open the live site link above, or download the repository and open index.html in a browser.
